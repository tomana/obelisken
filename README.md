# obelisken.no

The splash of [tomnaerland.com](https://tomnaerland.com) on its own: the IVAR / CHEOPS / KALLAX flip, then
the obelisk builds up from the ground and OBELISKEN comes in, with a quiet "tomnaerland.com →" under it
that opens the Work page.

One self-contained `index.html` (no build step), served by GitHub Pages from `main` at **obelisken.no**
(`CNAME`). Push to main = live.

The splash code is a copy of the one in tomnaerland.com's `index.html` (repo
[tomana.github.io](https://github.com/tomana/tomana.github.io)), not shared with it: a change to the
splash there has to be made here too. The fonts are Archivo 700 and Martian Mono 400 cut from the
variable fonts and subset to Latin, as WOFF2.
